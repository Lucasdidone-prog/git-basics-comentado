## Itens desta seção (3)

### 1. GitHub para Windows

<https://windows.github.com>

**Para que serve, e quando eu usaria:**

Serve para gerenciar e salvar seus projetos e códigos nos repositórios, usaria para organizar e salvar os meus projetos, podendo complementar e melhorar a partir das alterações previamente realizadas.

**Quando usar / observação:**

Agilidade no dia a dia, Para ver rapidamente quais linhas de código foram alteradas.
---

### 2. GitHub para Mac

<https://mac.github.com>

**Para que serve, e quando eu usaria:**

O GitHub Desktop para Mac serve também para gerenciar seus projetos através dos repositórios, permitindo maior organização.

**Quando usar / observação:**

Para guardar meus projetos, podendo melhorá-los e compartilhá-los.
---
